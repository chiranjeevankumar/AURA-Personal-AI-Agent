# AURA — Personal AI Agent

AURA is a personal AI agent designed to understand voice
instructions, plan tasks, use tools, control supported
device functions, communicate with services, remember
important information, and verify completed actions.

## Project Status

Day 1 — Foundation

## Main Goals

- Voice interaction
- Wake-word activation
- Personal memory
- AI planning
- Android device control
- Communication tools
- Web tools
- File tools
- Device integrations
- Automation
- Action verification
