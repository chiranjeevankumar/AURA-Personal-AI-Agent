# AURA Architecture

AURA is designed as a personal AI agent rather than a simple chatbot.

Core flow:

User Voice
    ↓
Voice Processing
    ↓
Agent Brain
    ↓
Intent Understanding
    ↓
Planning
    ↓
Permission Check
    ↓
Tool Selection
    ↓
Action Execution
    ↓
Result Verification
    ↓
Memory
    ↓
Response

The AI model is one component of the agent.
The agent itself consists of multiple cooperating systems.
